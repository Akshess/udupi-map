# 🌴 UdupiWalk

> A modern, community-driven guide to Udupi built with Next.js and TypeScript.

UdupiWalk is a web platform designed to help locals and tourists discover everything about Udupi in one place. Whether you're looking for beaches, temples, restaurants, bus routes, tourist attractions, or important city information, UdupiWalk aims to be the go-to digital guide for the city.

---

## ✨ Features

- 🗺️ Interactive map of Udupi
- 🚌 Bus routes and transportation information
- 🍽️ Restaurants and cafés
- 🏖️ Tourist attractions
- 🛕 Temples and heritage places
- 🌅 Beaches and viewpoints
- 📍 Location details with Google Maps integration
- 📱 Fully responsive design
- ⚡ Fast performance with Next.js

## 🛠️ Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/udupiwalk.git
```

Move into the project

```bash
cd udupiwalk
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
